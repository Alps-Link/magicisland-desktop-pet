# 阿尔卑斯桌宠 · 使用说明

8 只 Live2D 桌面宠物，每只都是独立的、住在桌面上的一个角色：
**阿尔卑斯 / 希雅拉 / 薇薇 / 可可 / 洛洛 / 莫娜卡 / 艾丽卡 / 卡梅莉亚**。

她会跟你聊天、记住你说过的事、慢慢形成对你的印象；你玩游戏看视频时她随口评论两句，
会陪你读书、给你放歌；也会累、会睡着，你回来找她又会醒。

| 角色 | 程序 | 角色 | 程序 |
|---|---|---|---|
| 阿尔卑斯 | `AlpsPet.exe` | 莫娜卡 | `MonakaPet.exe` |
| 希雅拉 | `ShearaPet.exe` | 艾丽卡 | `EricaPet.exe` |
| 薇薇 | `ViviPet.exe` | 卡梅莉亚 | `CarmeliaPet.exe` |
| 可可 | `CocoPet.exe` | 洛洛 | `RoroPet.exe` |

## 一分钟上手

**1. 下载 → 解压 → 双击**

成品压缩包在**百度网盘**：<https://pan.baidu.com/s/1L1Kmug1nU5xrdlyIfI09uA>　提取码：`9xvm`
（8 只各一个压缩包，下你想要的那只就行。）

解压后里面就是一个自包含的 exe（约 600MB），不用装 Python、不用装别的东西。
双击后要等一会儿界面才出来——它在把内容解压到临时目录（约 600MB），不是卡死。

**2. 填 API 密钥**（不做这一步她不会回话）

**右键点桌宠 → ⚙️ 设置 → API 密钥 → 文本模型设置…**，在「提供方预设」里选一个
（内置 DeepSeek 官方 / OpenAI / Moonshot Kimi / 智谱 GLM / 阿里通义 / SiliconFlow / OpenRouter / Ollama 本地），
填上你自己的 API Key，保存。想让她"看屏幕"就再配一下「视觉模型设置…」（可选）。

**3. 开始说话**

底部输入框打字回车；或者右键 → 🎮 模式 → 🎤 语音识别（开始），然后喊她的名字。

> 语音识别是**本地离线**的（sherpa-onnx Paraformer），不用联网、不用额外配置，开箱可用。

## 怎么操作

| 操作 | 效果 |
|---|---|
| **左键点一下**她身上 | 触摸反应（撒娇 / 惊讶 / 害羞，每只动作不同）；陪玩模式开着时会顺便看一眼你的屏幕 |
| **按住拖动** | 把窗口挪到桌面任意位置 |
| **右键** | 打开主菜单——所有功能都在这里 |
| 底部**输入框 + 回车** | 打字聊天（菜单里「显示/隐藏输入框」可以把它收起来） |
| **喊名字** | 语音唤醒：喊名字的前两三个字（"阿尔卑斯"…）；唤醒后 **8 秒内**可以直接接着说话，不用再喊 |

## 功能一览

| 功能 | 怎么开 | 说明 |
|---|---|---|
| 💬 对话 | 输入框 / 语音 | 回复控制在 70 字以内，开头带一个情绪（同时决定表情） |
| 🧠 记忆 | 自动 | 聊够一定量会自动提炼成"话题 / 事件"存进本地库，以后聊天会自然提起 |
| 🖼️ 性格画像 | 自动；菜单「📌 记忆锚点」里看 | 12 项固定条目 + 一句「关系形象」（她对你的认知）。宁缺毋滥，没观察到的就空着 |
| 🗒️ 话题 | 自动；「话题定时器设置…」可调 | 她会主动来找你聊，固定间隔或随机间隔都行 |
| 🎤 语音 | 「🎤 语音识别 (开始)」 | 本地识别、喊名字唤醒；识别结果当普通消息发出去 |
| 🔊 朗读 | 「🎵 TTS 设置」→「🔊 开启语音」 | **默认关闭**。默认音色是火山「声音复刻」，要你自己的火山 API Key + Speaker ID；没配就切到「Edge」，免费但需联网 |
| 🎮 陪玩 | 「🎮 陪玩模式 (开始)」 | 隔一段时间看一眼你的屏幕、随口评论（需要配「视觉模型」）。手动左键点她也会触发一次 |
| 📖 读书 | 「📖 陪我读书 (开始)」+「阅读设置」 | 先框选屏幕上的文字区域，本地 OCR 识别后陪你读 |
| 🎵 音乐 | 「🎵 音乐库设置…」 | 把歌放进曲库文件夹，对她说"放首歌"/"播放××"；她会**先说完话再放** |
| 💤 睡觉 / ⚡ 精力 | 菜单，或 60 分钟无互动自动睡 | 精力上限 100：清醒每分钟 −0.5、每次主动互动 −2、睡觉每分钟 +6；低于 30 显疲态、低于 10 有气无力 |
| ⚙️ 缩放 | 「缩放设置…」 | 角色大小、气泡、输入框、窗口宽度、聚焦缩放分别可调 |

## 常见问题

**她不回话？** 多半是第 2 步没做：右键 → ⚙️ 设置 → API 密钥 → 文本模型设置，填 Key 保存。
**说话没声音？** TTS 默认关闭：菜单「🎵 TTS 设置」→「🔊 开启语音」。开了还没声就检查音色——默认的"声音复刻"要填火山 API，或者用「🔄 切换 TTS」切到 Edge。
**点「语音识别」弹"模型未就绪"？** 那是**源码运行**时缺语音模型文件，成品 exe 不会遇到（见 `SETUP.md`）。
**窗口太大 / 太小？** ⚙️ 设置 →「缩放设置…」。
**她怎么自己睡了？** 60 分钟没互动会自动睡；点她一下或跟她说话就醒。也可以手动「💤 睡觉」。
**会偷看我屏幕吗？** 只有你开了「陪玩模式」才会截屏，而且只发给你**自己配置**的视觉模型。聊天记录、记忆、API Key 全在本地 `userdata\`，不上传到别处。
**能改人设吗？** ⚙️ 设置 →「系统提示词与角色…」。8 只的人设档案在仓库 `角色设定/`。

## 数据存在哪

全在程序目录下的 `userdata\`（删掉它就等于恢复出厂）：

| 文件 / 目录 | 内容 |
|---|---|
| `llm_config.json`、`*_api_key.json` | API 地址、密钥、模型名 |
| `memories.json`、`memory.db` | 记忆（话题、事件、性格画像、关系形象） |
| `chats.json` | 聊天历史 |
| `topic_config.json`、`topic_history.json` | 话题定时器与话题历史 |
| `watch_config.json`、`reading_config.json`、`zoom_config.json`、`tts_config.json` | 各功能设置 |
| `music\` | 音乐库（往里放 mp3 / flac / ogg / wav） |
| `{角色}.log` | 运行日志——出问题先看它 |
